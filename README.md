# Network Protocols App

Android-клиент экспериментального стенда для сравнительной оценки REST, SOAP, GraphQL, gRPC и WebSocket в сценариях клиент-серверного взаимодействия.

## Назначение

Приложение запускает измерительные серии с экрана Android-устройства. Пользователь указывает адрес backend, задает число измеряемых запусков и выбирает полный тест либо отдельный набор по протоколу или сценарию.

Основной блок измерений производительности выполняется из интерфейса приложения. Отдельный ADB-контур используется только для ресурсного блока, где требуется фиксировать системный отчет `batterystats` между нагрузочными блоками.

## Возможности

- Проверка доступности backend по HTTP и gRPC.
- Запуск полного набора поддерживаемых сочетаний протоколов, сценариев и режимов соединения.
- Отдельные запуски по выбранному протоколу или сценарию.
- Отображение прогресса, текущей серии, оценки оставшегося времени и краткого результата.
- Экспорт краткого и полного текстового отчета.
- Сбор клиентских задержек, пропускной способности, ошибок, потоковых показателей, служебных сигналов и телеметрии устройства.

## Сценарии

- `S1` - короткое чтение.
- `S2` - полный большой объект.
- `S3` - частичная проекция объекта.
- `S4` - список объектов.
- `S5` - малая запись с подтверждением.
- `S6` - большая запись с подтверждением.
- `S7` - поток малых событий.
- `S8` - поток больших событий.
- `S9` - длительная сессия.

Режим `h_req` измеряет обращение с подготовкой соединения для каждого запроса. Режим `h_series` измеряет серию с заранее подготовленным соединением.

## Структура проекта

- `app` - точка входа приложения.
- `client` - экраны, навигация и UI запуска измерений.
- `domain:api` - доменные модели, сценарии, протоколы и интерфейсы раннера.
- `domain:impl` - сетевые клиенты, выполнение измерений, сбор телеметрии и формирование отчетов.
- `core:designsystem` - общие UI-компоненты.
- `core:base` - базовые вспомогательные компоненты.

## Сборка и запуск

```bash
./gradlew :app:assembleDebug
```

Проверка компиляции:

```bash
./gradlew :app:compileDebugKotlin
```

Порядок запуска стенда:

1. Запустить backend-сервис.
2. Установить отладочную сборку на Android-устройство.
3. Указать в приложении адрес backend.
4. Выполнить проверку стенда.
5. Запустить нужный набор измерений.

## Ресурсный блок

Вспомогательный сценарий для оценки расхода заряда находится в `tools/energy_benchmark/`. Он запускает фиксированные нагрузочные блоки через ADB и сохраняет системные отчеты Android:

```bash
tools/energy_benchmark/run_energy_benchmark.sh \
  --host 192.168.1.140 \
  --duration-seconds 300 \
  --idle-seconds 600 \
  --output-dir energy_reports
```

Этот контур относится только к измерению характеристик энергопотребления; основной тест производительности запускается из интерфейса приложения.
